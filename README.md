# QuantResearch

Платформа количественного исследования фондового рынка, разработки, тестирования и анализа торговых стратегий.

Основные технологии: **Python, Backtrader, FinLabPy, FinamPy, MOEXPy и JupyterLab**.

## Установка и запуск

Подробная инструкция по клонированию репозитория, установке Python-зависимостей, настройке API-токенов и запуску QuantResearch:

**[Инструкция по установке и запуску QuantResearch](docs/installation.md)**

## Работа с JupyterLab

JupyterLab используется для разработки торговых стратегий, запуска бэктестов и анализа результатов.

Запуск из корневого каталога проекта:

```bash
uv run jupyter lab
```

Подробности: [Руководство по работе с JupyterLab и Jupyter Notebook](docs/jupyterlab.md).

## Структура проекта

```text
QuantResearch/
├── Data/                 # Локальные исторические данные
├── docs/                 # Документация
├── external/             # FinamPy, FinLabPy, MOEXPy
├── quant_tools/          # Общие инструменты количественного анализа
├── research/             # Исследования и торговые стратегии
│   ├── _template/        # Шаблон исследования
│   ├── sma_cross/        # Исследование стратегии пересечения SMA
├── scripts/              # Служебные скрипты
├── logs/                 # Локальные журналы
├── .env.example          # Шаблон переменных окружения
└── pyproject.toml        # Конфигурация Python-проекта
```

Каталоги `.venv/`, `Data/` и `logs/` используются локально. Секреты из `.env` не должны попадать в Git.

## Разработка торговых стратегий

Исследования размещаются в каталоге `research/`.

Основой для нового исследования служит `research/_template/`, содержащий:

- `backtest.ipynb` — Jupyter Notebook для запуска и анализа бэктеста.
- `strategy.py` — модуль торговой стратегии Backtrader.
- `README.md` — описание исследования.

Для создания новой стратегии скопируйте `_template/` в отдельный каталог `research/`, например `research/my_strategy/`.

Общие компоненты, такие как модели комиссий, индикаторы, анализаторы и средства визуализации, размещаются в пакете `quant_tools/`.

## Основные компоненты

- **Backtrader** — разработка и бэктестинг торговых стратегий.
- **FinamPy** — интеграция с Finam Trade API.
- **MOEXPy** — работа с биржевыми данными.
- **FinLabPy** — интеграция брокеров и рыночных данных с Backtrader.
- **JupyterLab** — интерактивная исследовательская среда.
- **uv** — управление Python-зависимостями и виртуальным окружением.

## Хранение данных

Исторические рыночные данные размещаются в локальном каталоге `Data/`, который исключён из Git.

Результаты исследований и механизмы их постоянного хранения будут разработаны на следующих этапах.
