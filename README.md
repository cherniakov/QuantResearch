Платформа количественного исследования фондового рынка, разработки, тестирования и анализа торговых стратегий.

## Основные компоненты

- **Backtrader** — разработка и бэктестинг торговых стратегий.
- **FinamPy** — интеграция с Finam Trade API.
- **MOEXPy** — работа с биржевыми данными.
- **FinLabPy** — интеграция брокеров и рыночных данных с Backtrader.
- **uv** — управление Python-зависимостями и виртуальным окружением.
