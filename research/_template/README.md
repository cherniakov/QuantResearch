# Шаблон торговой стратегии QuantResearch

Каталог `_template` предназначен для создания новых исследовательских проектов и тестирования торговых стратегий с использованием FinLabPy и Backtrader.

## Состав

- `backtest.ipynb` — Jupyter Notebook для запуска и анализа бэктеста.
- `strategy.py` — Python-модуль для торговой стратегии (добавляется по мере разработки).

## Создание нового исследования

1. Скопируйте каталог `_template` в `research/` под новым именем, например `sma_cross`.
2. Откройте скопированный `backtest.ipynb` в JupyterLab.
3. Настройте инструмент, временной интервал и параметры тестирования.
4. Разработайте или подключите торговую стратегию.
5. Выполните бэктест и проанализируйте результаты.

## Запуск JupyterLab

Из корневого каталога QuantResearch:

```bash
uv run jupyter lab
```

Подробная инструкция находится в `docs/jupyterlab.md`.

## Общие инструменты

Повторно используемые компоненты размещаются в пакете `quant_tools`, включая модель комиссий Finam `FinamCommission`.
