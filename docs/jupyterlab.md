# Работа с JupyterLab в QuantResearch

JupyterLab — интерактивная среда QuantResearch для исследования фондового рынка, разработки торговых стратегий и запуска бэктестов с использованием Backtrader.

## 1. Подготовка окружения

Следуйте [инструкции по установке QuantResearch](installation.md). В корне проекта должны быть установлены зависимости:

```bash
uv sync --locked
```

JupyterLab и `ipykernel` входят в зависимости QuantResearch. Отдельно устанавливать их не требуется.

## 2. Запуск JupyterLab

Откройте терминал в корневом каталоге QuantResearch:

```bash
uv run jupyter lab
```

JupyterLab запустит локальный сервер. Обычно браузер откроется автоматически. В противном случае используйте адрес из вывода терминала, например `http://localhost:8888/lab?token=...`.

Адрес с токеном доступа к JupyterLab не следует публиковать или пересылать посторонним.

Пока вы работаете в JupyterLab, оставьте терминал сервера открытым.

## 3. Открытие шаблона бэктеста

В файловом обозревателе JupyterLab откройте:

```text
notebooks/backtest_template.ipynb
```

Шаблон предназначен для знакомства с запуском Backtrader. В нём используются демонстрационные (синтетические) данные, поэтому для его выполнения не требуются API-токены и подключение к брокеру.

Чтобы сохранить исходный шаблон без изменений, используйте **File → Save Notebook As…** и создайте собственную копию.

## 4. Проверка Python-ядра

При открытии ноутбука выберите ядро **Python 3 (ipykernel)**. Для проверки выполните ячейку:

```python
import sys
print(sys.executable)
```

Путь должен вести к виртуальному окружению проекта, например:

```text
.../QuantResearch/.venv/bin/python
```

Если используется другой интерпретатор, выберите ядро, соответствующее `.venv` QuantResearch, через меню выбора ядра JupyterLab.

## 5. Работа с ячейками

- **Shift + Enter** — выполнить текущую ячейку и перейти к следующей.
- **Run → Run All Cells** — выполнить все ячейки ноутбука по порядку.
- **Cmd + S** на macOS — сохранить ноутбук.
- **Kernel → Restart Kernel** — перезапустить Python-ядро и сбросить состояние переменных.

Ячейки зависят от состояния ядра. Для воспроизводимого исследования запускайте их последовательно сверху вниз. При необходимости перезапустите ядро и повторите выполнение всех ячеек.

## 6. Запуск демонстрационного бэктеста

В `notebooks/backtest_template.ipynb` выполните ячейки по порядку. Шаблон включает импорт библиотек, параметры эксперимента, определение стратегии, подготовку данных, запуск Backtrader и просмотр результатов.

После выполнения проверьте вывод бэктеста, включая стартовый и конечный капитал. Значения зависят от параметров и данных, используемых в ноутбуке.

Пример с синтетическими данными не размещает реальные заявки у брокера. Перед запуском других примеров FinamPy или FinLabPy изучайте код: некоторые из них могут выполнять торговые операции.

## 7. Создание собственных исследований

Создавайте отдельные ноутбуки в `notebooks/`, чтобы не изменять исходный шаблон. Для воспроизводимости фиксируйте в тексте ноутбука:

- источник данных и используемый период;
- параметры стратегии и начальный капитал;
- комиссии и другие настройки моделирования;
- основные результаты и выводы.

Не записывайте API-токены, пароли и другие секреты в ячейки ноутбуков. Для доступа к брокерским API используйте локальные настройки, описанные в [инструкции по установке](installation.md).

## 8. Сохранение и публикация ноутбуков

Сохраняйте изменения через **File → Save Notebook** или **Cmd + S**.

Перед добавлением демонстрационных ноутбуков в Git рекомендуется очищать результаты выполнения через **Edit → Clear Outputs of All Cells**. Это уменьшает размер файлов и предотвращает случайную публикацию локальных данных.

Если очистка через интерфейс не сработала, можно закрыть ноутбук и выполнить из корня проекта:

```bash
uv run jupyter nbconvert --ClearOutputPreprocessor.enabled=True --inplace notebooks/backtest_template.ipynb
```

Не сохраняйте после этого открытую в редакторе старую версию файла, иначе результаты могут вернуться.

## 9. Остановка сервера

Вернитесь в терминал, где работает JupyterLab, и нажмите **Ctrl + C**. Если появится запрос подтверждения остановки сервера, введите `y` и нажмите Enter.

Перед остановкой сохраните изменения в открытых ноутбуках. Остановка сервера не удаляет сохранённые файлы.

## 10. Типичные проблемы

**Ноутбук использует не тот Python.** Проверьте `sys.executable` и выберите ядро из `.venv` QuantResearch.

**Библиотека не импортируется.** В корне QuantResearch выполните `uv sync --locked`, затем перезапустите ядро.

**Порт 8888 занят.** Используйте адрес, указанный в терминале JupyterLab: сервер может автоматически выбрать другой порт.

**Результаты не обновляются.** Перезапустите ядро и выполните ячейки в порядке следования.
